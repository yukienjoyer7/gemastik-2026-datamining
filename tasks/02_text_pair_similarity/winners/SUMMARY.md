## 2. Distilled Architectural Playbook

### A. Preventing Transitive Graph Leakage in Validation (`eda_and_data.py`)
- Never use naive `KFold` or `StratifiedKFold` on pair datasets where entities repeat across rows!
- If `(A, B)` is in train and `(B, C)` is in validation, a Cross-Encoder memorizes entity `B`'s target prior.
- Always run Union-Find (`analyze_pair_graph` in `eda_and_data.py`) on `train` and split using `StratifiedGroupKFold` grouped by **connected component ID** (or anchor ID).

### B. Why "Magic" Graph Features Dominate Pair Datasets (`baselines/tier1_fast_cpu.py`)
- Real-world pair datasets (duplicate questions, entity resolution, citation links) are generated by sampling positive/negative candidate pairs from an underlying entity graph.
- High-degree hub nodes have a much higher base rate of being duplicates, and two nodes sharing $\ge 1$ common neighbor in the candidate graph (`shared_neighbors > 0`) are **5x–20x** more likely to be true matches.
- `PairGraphFeatureExtractor` (`modules/pair_features_and_biencoder.py`) extracts all 15 topological features (degrees, common neighbors, Adamic-Adar, component size, PageRank, 2-hop Personalized PageRank affinity) in $O(E \cdot d_{\max})$ time.

### C. Cross-Encoder Tricks (`baselines/tier2_strong_dl.py` & `postprocess.py`)
1. **Context-Grouping Augmentation:** When multiple candidate pairs share an anchor/context, append peer candidates to the prompt so self-attention calibrates similarity scores across the anchor's full comparison set.
2. **Symmetric Test-Time Augmentation (TTA):** When similarity is symmetric ($S(A, B) = S(B, A)$), average forward and swapped passes: $\hat{y} = 0.5 f(A, B) + 0.5 f(B, A)$. Consistently gives $+0.002$ to $+0.005$ Pearson / AUC for zero extra training cost.
3. **Transitive Triangle Adjustment (`postprocess.py`):** If a component contains triangle edges $(A, B)$ and $(B, C)$ with high predicted probability, propagate $P(A, C) \leftarrow (1-\alpha)P(A, C) + \alpha (P(A, B)\cdot P(B, C))$.
